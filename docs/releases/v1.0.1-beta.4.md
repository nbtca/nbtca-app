## beta.4 修复重打

本 release 已替换为合并 PR #4 后的版本，修复 issue #3。版本名仍为 1.0.1-beta.4，Android versionCode 增加到 1000105。

已安装旧 beta.4 的用户请从本页重新下载 APK 覆盖安装；由于版本名未变，旧版的应用内更新提示可能不会出现。

## 更新内容

- Card 恢复使用维护者支持的 Cloudflare Access / Logto 网页登录，授权后缓存 CF_Authorization 会话。
- 页面、图片和上传使用 Card 官方常规 URL，移除已下线的 /native 路由和专用 Token 依赖。
- 保留原生卡面、社员墙、图片缓存、裁切与动态活动券效果。
- 适配上游按活动要求提供的姓名、学号、班级、手机号字段，校验提交结果，避免错误提示为领取成功。
- 加入上游接口源码变更检查，每日及相关代码变更时报告需要复核的接口文件。
- 保留 NBTCA 主登录的刷新令牌与 OAuth state 校验修复。

## 验证与限制

- 本地 18 项单元测试、Release 构建通过。
- 实机已验证官方会话读取、个人卡片图片、16 位社员的社员墙图片及活动空状态。
- 真实上传保存、领券和核销尚未完成端到端实测。
- Card 会话过期后仍需按官方网页登录流程重新授权。
