## 更新内容

- Card 统一使用 App 的 NBTCA / Logto 登录，无需单独获取 Cloudflare 网页授权。
- 自动申请和续期 Card 专用 Token；页面、图片与上传请求统一使用同一 NBTCA 身份。
- 修正长期登录授权参数，使 Logto 正常签发刷新令牌；补充 OAuth 回调 state 校验。
- Card 图片缓存改为按 NBTCA 账号隔离。
- 补齐 Logto 授权页 WebView 视口高度兼容处理。

## 升级说明

旧版本登录可能没有刷新令牌。升级后若提示登录需要更新，请重新登录 NBTCA 账号一次；此后 Card 直接复用 App 身份，重启 App 后无需单独授权。

本版本依赖已部署的 Card 原生认证入口。配套服务端改动见 https://github.com/nbtca/card/pull/38 ，包括动态图片路由修复；发布时该 PR 的维护者审核仍待完成。
